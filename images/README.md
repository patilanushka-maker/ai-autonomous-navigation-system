# Images Directory

This directory contains visual assets and screenshots for the repository documentation:

1. `simulation_studio_preview.png`: Pre-simulation 2D occupancy grid workspace preview showing obstacles, free drivable space, start pose with robot footprint circle, heading orientation arrow, and goal marker.
2. `navigation_trajectory.png`: Post-simulation trajectory visualization showing planned A* waypoints, continuous unicycle robot trajectory, final robot pose, and execution metrics.

Users can add additional application screenshots or video frames to this directory as needed.
