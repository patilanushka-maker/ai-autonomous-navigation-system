# Images and Visual Assets

This directory contains visual assets, web interface captures, demonstration plots, and video recordings for the AI-Based Autonomous Navigation System documentation.

## Directory Structure

### Root Plots
* `simulation_studio_preview.png`: Pre-simulation 2D occupancy grid workspace preview illustrating obstacles, free drivable space, start pose with circular robot footprint ($R$), heading vector, and target marker.
* `navigation_trajectory.png`: Post-simulation trajectory visualization showing planned A* waypoints, continuous unicycle trajectory trail, terminal robot pose, and execution metrics banner.

### Web Interface Captures (`Web interface/`)
* `Simulation studio.jpg`: Overview of the interactive Streamlit Simulation Studio dashboard with parameter controls and configuration panels.
* `Environment map preview.jpg`: Real-time pre-flight map inspection showing grid coordinate axes, obstacle footprint, start heading vector, and target location.
* `Simulation execution results.jpg`: Closed-loop execution telemetry displaying the continuous robot trajectory trail, step counts, path length, and final goal status.
* `Benchmark suite.jpg`: Automated benchmark runner overview evaluating scenarios across the standardized benchmark suite.
* `Benchmark open_space.jpg`: Detailed single-scenario benchmark telemetry execution for the open space test environment.
* `Architecture.jpg`: Interactive documentation page presenting system architecture diagrams, mathematical equations, and module definitions.
* `web recording.mp4`: Complete screen capture demonstrating interactive map editing, configuration changes, simulation execution, and benchmark runs in the browser.

### Verification and Proof (`Github proof/`)
* `Github screenshot.jpg`: Verification capture of GitHub repository initialization and setup.
