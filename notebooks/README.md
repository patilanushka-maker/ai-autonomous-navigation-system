# Notebooks Directory

This directory is designated for exploratory analysis, educational demonstrations, and interactive experiments:
- **A* Algorithm Exploration**: Step-by-step heuristic exploration and open/closed set visualization.
- **Kinematics & Control Sandbox**: Proportional control parameter ($K_p$) tuning and unicycle trajectory response curves.
- **Scenario Benchmark Walkthroughs**: Interactive walkthroughs of navigation missions.

> **Status Notice**: Notebooks will be added alongside the corresponding module implementations to avoid empty or broken notebooks.
